# Secure Password Vault

A secure password manager that keeps your logins safe outside of browsers.

## Download
Go to **Actions** tab → Click latest workflow → Download artifacts (SecureVault-x86 and SecureVault-x64)

## Features
- AES-256 encrypted storage
- Master password protection
- Launch websites with copied credentials
- No cloud storage - everything local

## How to use
1. Download the EXE for your Windows (x86 or x64)
2. Run it and create a master password
3. Add your website logins
4. Use "Launch & Login" to open sites with auto-copied credentials
